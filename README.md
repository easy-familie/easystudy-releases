# EasyStudy

Studium planen: Semester, Fächer, Lernpläne, Termine und Noten an einem Ort. Teil der Easy-Familie.

## Download

Unter [Releases](../../releases/latest) die neueste Version laden (DMG oder Zip, Mac mit Apple Silicon). EasyStudy in den Ordner **Programme** ziehen und öffnen. Danach meldet sich die App selbst, wenn es Updates gibt.

Dieses Repository enthält nur fertige Versionen, keinen Quellcode.
